# List of software #
This is a list of software required or recommended in this course, with links to insllation guides.  
Most of it can be installed using [Anaconda:](https://www.anaconda.com/docs/main) which is a software manager to install python and python libraries, so it is recommended to start first by installing it.

## Molecular Modelling and simulation software ##
- Visual Molecular Dynamics [VMD](https://www.ks.uiuc.edu/Development/Download/download.cgi?PackageName=VMD) version 2
- [OpenMM](https://docs.openmm.org/latest/userguide/application/01_getting_started.html#installing-openmm) Instructions to install from anaconda [here](https://anaconda.org/channels/conda-forge/packages/openmm/overview)
- [Avogadro](https://avogadro.cc/install/index.html)

## Python Libraries: ##
