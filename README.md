# Softmatter simulation: Materials for an Introductory course

This repository contains materials for an introductory course on simulation of Softmatter at the Master level, based on our research in Softmatter at Institut de Ciencia de Materials de Barcelona (ICMAB-CSIC) [Soft Matter Theory Research Unit - ICMAB-CSIC](https://icmab.es/ts/softmattertheory)

This version corresponds to the materials used in the first part of the **Soft Matter Simulation** modules [(syllabus available here)](https://apps.uab.cat/guies/public/html/2026/assignatura/45739/en) from the [UAB masters degree in Applied Nanoscience](https://www.uab.cat/web/estudiar/official-master-s-degrees/content/study-plans-and-timetables/applied-nanoscience-from-materials-to-devices-1096480963070.html?param1=1345967786281)
